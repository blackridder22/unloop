# Approved design source

Paper file: https://app.paper.design/file/01M2S5JJG1564SVSG7J1EZDGTQ/p-1-0

The implementation uses Paper's direct JSX export values: 96px header / 48px horizontal padding, 760px search column, 184px top spacing, 56/64px Geist heading, 72px search field, 48px action, and a 1040px 16:9 player with 20px spacing and 22/28px metadata title.

The player frame in Paper is illustrative content. The extension keeps YouTube's real player and native captions, volume, seeking, speed and fullscreen controls. Creator and search results use YouTube's real content. New responsive behavior and completion state follow the same tokens.
